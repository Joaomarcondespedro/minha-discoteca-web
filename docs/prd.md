Objetivo Principal
O "Minha Discoteca" é uma aplicação web voltada para audiófilos e colecionadores de mídias físicas (Vinis, CDs e K7s). O objetivo é permitir que o usuário cadastre, gerencie e visualize sua coleção de forma organizada, exibindo informações como artista, álbum, ano de lançamento, gênero e formato da mídia.

Histórias de Usuário
Como usuário, quero poder cadastrar um novo disco informando o título, artista, gênero, ano e formato, para manter minha coleção atualizada.

Como usuário, quero visualizar todos os meus discos cadastrados em formato de "estante virtual" (Cards) para localizar rapidamente os discos que possuo.

Como usuário, quero poder buscar informações e a capa de um álbum automaticamente usando uma API pública (ex: iTunes API) para facilitar o cadastro.

Como usuário, quero poder excluir ou editar um disco caso eu o venda ou tenha digitado algo errado.

Como usuário, quero poder selecionar discos da estante e adicioná-los a uma fila de reprodução, para manter uma lista do que planejo ouvir em seguida, mesmo após fechar o navegador.
